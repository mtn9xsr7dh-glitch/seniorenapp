# Rentner App

Eine einfache Web-App für Senioren, um Betrug zu vermeiden und Smartphone-Probleme mit KI-Hilfe zu lösen.

## Funktionen

- **Betrug vermeiden**: Lernen Sie über Online- und Telefon-Betrug mit Text und Audio.
- **Smartphone Hilfe**: Stellen Sie Fragen zu Ihrem Smartphone und erhalten Sie Schritt-für-Schritt-Anleitungen in Text und Audio mit Pausen.

## Installation

1. Installieren Sie Node.js von [nodejs.org](https://nodejs.org/).
2. Klonen Sie das Repository.
3. Führen Sie `npm install` aus.
4. Starten Sie die App mit `npm run dev`.

## Verwendung

- Öffnen Sie die App im Browser.
- Navigieren Sie zu "Betrug vermeiden" für Tipps.
- Verwenden Sie "Smartphone Hilfe", um Fragen zu stellen und Anleitungen zu erhalten.

## Technologien

- React
- TypeScript
- Vite
